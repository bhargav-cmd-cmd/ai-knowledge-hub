# AI Knowledge Hub

## Project Objective
Build an intermediate-level AI-powered document intelligence web application.

## Technology Stack
- Frontend: Next.js, HTML, CSS, JavaScript
- Backend: Python FastAPI
- Database: SQLite with SQLAlchemy
- AI: PDF extraction, embeddings, vector search, LLM

## Main Features
- User registration and JWT login
- PDF document upload and management
- Document text extraction
- Semantic document search
- AI question answering with citations
- Chat history
- Responsive dashboard
